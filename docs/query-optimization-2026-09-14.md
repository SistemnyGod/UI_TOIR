## Изменения

- PPE items: SQL-фильтр по активному состоянию, типу и категории перед Count/Skip/Take. Сохранены признаки PPE: ppe/siz, СИЗ, спец, glove, категории СИЗ/спецодеж/PPE. Поиск и categoryId применяются на сервере. Категория и название остаются ключами сортировки; Id добавлен для однозначного порядка при совпадениях. Сравнение/порядок текста теперь определяются collation PostgreSQL; редкие отличия от .NET culture sort возможны.
- Контроллер не загружает все страницы для одного запроса поиска. Формат ответа, максимальная страница 100 и PageCount=1 для пустого PPE-результата сохранены.
- PPE options использует тот же SQL-фильтр: остальные активные товары не материализуются. Полный набор СИЗ в options пока сохраняется для совместимости.
- Для пустой страницы не выполняется запрос остатков. Для непустой — один агрегат только по идентификаторам страницы.
- ЭМУ dashboard не загружает полные коллекции AuditEvents и Pauses; RecentEvents получает только 10 записей, без Include полной работы. Участники, интервалы участия, вложения и ограничения доступа сохранены.
- Список работ ЭМУ и выдача изменений не загружают историю аудита, не используемую mapper. Паузы и интервалы сохранены, поскольку нужны расчёту времени. Выдача изменений использует AsNoTracking. Расчётные отчёты и изменение работ сохраняют прежнюю полную загрузку.
