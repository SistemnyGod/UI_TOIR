## Дефекты, подтверждённые исходным аудитом

- P2: RouteCreateModal теряет добавленные точки после Escape и повторного открытия.
- P2: SettingsModal оставляет фокус на фоне, не обрабатывает Escape.
- P2: ReferenceModal можно закрыть во время незавершённого сохранения.
- Читаемость: избыточная высота служебных панелей результатов; вложенная прокрутка на телефоне.
- Структура: несколько оболочек модалок и последовательные CSS-переопределения.

## Инварианты и выполнение

- Использовать существующую палитру ATOM и канонические токены.
- Проверять текущие файлы перед изменением; сохранять существующую работу в дереве.
- Сохранять API, идентификаторы и мобильные контракты. Изменения backend согласовываются отдельно, если понадобятся.
- Статистика остаётся достоверной; тестовый режим обозначается явно.
- Рабочий сервер не обновляется в рамках этой цели. Временный локальный стенд останавливается после проверки.
- Статус каждого требования меняется только по фактическим результатам. Итог включает ограничения и ссылки на доказательства.
