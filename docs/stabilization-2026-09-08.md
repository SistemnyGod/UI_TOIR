# Стабилизация Patrol360 — 8 сентября 2026

Основные исправления реализованы в ветке `codex/patrol-stabilization`. Изменения пока не закоммичены; базовый commit `875e543b2c0a30795756b1d9e7cd19e43566dfc0`. Рабочий сервер, телефоны и worktree `556a` не переключались. Это внутренний кандидат с незавершённой приёмкой.

## Что изменено

- Области ЭМУ: `null` — глобальная область, пустой список — нет доступа, включая запрос замечаний без участка.
- Файлы mobile: неизменяемый владелец и цель при повторе `clientFileId`, непубличная промежуточная загрузка, подтверждение привязки после принятой outbox-команды. Списки и скачивание учитывают `LinkedAt`. Чужой UUID замечания возвращает конфликт. Отклонённая команда откатывается к savepoint.
- Добавочная миграция `20260908090000_ConfirmMobileAttachmentLinks` подтверждает только доказуемые исторические связи; спорные записи сохраняет в `mobile_attachment_migration_review`, без удаления файлов.
- PERCo: общий advisory lock и транзакция чтения/удаления/сохранения, согласованные ручные корректировки. Сетевые обращения снаружи транзакции.
- ЭМУ: проверки занятости и плановой задачи после общей блокировки при создании, присоединении, замене и возобновлении.
- Результаты обходов: устранён цикл обновлений API-режима, сохранены mock-настройки и поиск.
- Worker: независимые циклы push/PERCo/ЭМУ, отдельные scopes, ограниченные повторы push timeout, корректная остановка, heartbeat с последним успехом и ошибкой каждого направления.
- Android: SQLite-маркер перехода атомарен с заменой БД; единая версионированная запись SecureStore с совместимым чтением. После замены БД прежняя сессия не восстанавливается; незавершённый переход требует целевого аккаунта. Ошибка очистки фото не откатывает вход, запрет смены при очереди сохранён.
- Первичный администратор требует явного секрета и смены пароля. Существующие аккаунты не меняются.
- Выпуск: native-команды проверяют exit code, неуспешная web-сборка останавливает публикацию. Подготовлены HTTPS, манифест происхождения, revision серверных сборок и Android. Исправлены ошибки нагрузочных скриптов; нагрузка не проводилась.
- Крупные файлы разделены без повышения лимитов: EF mobile mapping, PERCo/назначения web, mock Inventory, CSS. Устранены ошибки кодировки и форматирования обязательной проверки.

## Зависимости и незавершённая приёмка

Web: Vite 7.3.6 и совместимые transitive patches установлены; все обнаруженные ранее web advisory ranges устранены. NuGet не сообщил известных уязвимостей. Повторный финальный online audit web прервался по сети.

Mobile: обновление зависимостей заблокировано повторными тайм-аутами официального npm; исходный lockfile восстановлен, исправления приложения сохранены. Остаётся исходный online baseline: 15 affected package entries, из них 10 high / 4 moderate / 1 low. Это не 15 независимых эксплуатируемых дефектов APK: часть записей — транзитивные цепочки одного advisory.

Runtime-проверки требуют `expo-router → query-string → decode-uri-component`. Инструментальные цепочки включают `@babel/core`, `@expo/metro`, `metro`, `metro-config`, `metro-transform-worker`, `image-size`, `browserslist`, `@xmldom/xmldom`, `brace-expansion`, `js-yaml`, `nanoid`, `shell-quote`; их классификация описывает назначение цепочки, а не только npm-флаг dev. Полные диапазоны и ссылки сохранены в audit JSON.

До рабочего выпуска обязательны: завершить совместимые mobile security updates и пересобрать; проверить подписанный Release APK на физическом Android, доверие HTTPS-сертификату и реальные offline/recovery сценарии; восстановить настоящую резервную копию в изолированной БД и проверить данные/файлы; закрепить чистый commit и финальный манифест. Эти ворота пока не пройдены. Полноценная нагрузка, оптимизация запросов, интерфейс и очистка остаются следующими этапами.

Инструкция выпуска и согласованного отката: `docs/release-and-rollback.md`. Старый API нельзя просто подключать к данным с новыми промежуточными вложениями: он не знает границу подтверждённой привязки.
