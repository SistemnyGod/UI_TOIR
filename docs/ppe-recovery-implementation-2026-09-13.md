## Что исправлено

- Конструктор из worktree `556a` перенесён в основной проект: сотрудник и применимая норма → подбор → количество, размер, цена и дата → предварительный документ → подтверждение → история. Исходный worktree сохранён отдельно; перед переносом сохранены патчи и архив в `.codex-tmp/ppe-integration-20260913`.
- Черновик выдачи отделён от факта подтверждения. DOCX доступен до подтверждения. Повтор подтверждения с тем же ключом не создаёт второй документ; подтверждённый документ использует сохранённый снимок данных.
- Исправлены автосохранение при повторном открытии, запоздалые ответы при смене сотрудника/сессии и гонки сохранения. Пользователь с правами просмотра может открыть историю, но не менять документ.
- Связанный товар получается точно по ID. Поиск по названию среди первых 30 результатов больше не определяет товар для выдачи. Пустая марка связанного товара не означает отсутствие связи.
- Убрана автоматическая подстановка `п. 1645` в новых операциях и печати. Исторические миграции и существующие рабочие значения не переписывались.
- Исправлены учёт релевантной истории требований нормы и конкурентный перенос legacy-карточки. Непроверенные нормативные области и сопоставления не становятся подтверждёнными автоматически.
- Старый маршрут PDF карточки теперь использует полный DOCX и общий конвертер вместо ограниченного старого генератора. Новый конвертер ограничивает время и размер ответа, проверяет PDF и возвращает понятную ошибку. Это изменение требует работающего Gotenberg и для старого PDF-маршрута.
- Поля конструктора помещаются на desktop и телефоне, цена поддерживает ввод дробной части, история показывает русские статусы. Убрано отдельное дублирующее CSS-переопределение.
- Ошибки API раскрывают конкретную причину блокировки. На настоящем API проверено сообщение о превышении нормы; при недоступности PDF показано: «Конвертер PDF недоступен. DOCX можно скачать сразу; PDF повторите позже».

Скрипт блокирует другой адрес/порт/имя БД, проверяет внешние команды и занятый порт API. При повторе создаёт отдельного синтетического сотрудника и норму, не удаляя предыдущую историю. `-KeepApiRunning` оставляет локальный API для браузерной проверки.

Запустить локальный Gotenberg и выполнить opt-in тест `RealGotenbergGeneratesLongSyntheticDocxAndPdfWhenExplicitlyEnabled`, визуально проверить обе PDF-формы, кириллицу, все 54 строки, переносы и повторение заголовков. Текущая загрузка официального Docker-образа дважды завершилась TLS-ошибкой `server did not echo the legacy session ID`. Это не повод отключать TLS-проверку. Настоящий PDF в этом проходе не получен.

3. На копии рабочих данных проверить и подтвердить применимость норм и сопоставления товаров ответственным пользователем. Не подменять отсутствие основания выдуманным пунктом и не объявлять старую неизвестную историю проверенной.
4. Выполнить предусмотренную приёмку восстановления резервной копии и отдельно согласовать рабочий выпуск. Нагрузочная приёмка и физические телефоны не проверялись в рамках восстановления СИЗ.

Откат пилота — выключение флага с сохранением новых таблиц, снимков и истории. После появления документов не выполнять Down-миграцию и не удалять спорные данные. При возврате к старому экрану оставить конвертер: обновлённый legacy PDF также использует его. Для отката к старым бинарным файлам нужно отдельно учитывать возвращение старых дефектов печати. HTTP/HTTPS и мобильные клиенты этим изменением не переключаются.
