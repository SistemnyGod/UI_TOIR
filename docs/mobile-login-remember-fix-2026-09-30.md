# Исправление сохранения входа в мобильном приложении

Дата: 30 сентября 2026 года. Проект: `mobiel proekt`.

## Причина

В `LoginScreen.tsx` галочка сохраняла только логин. Пароль явно удалялся при обычном входе и при подтверждении биометрии; при открытии экрана читался только логин. Подпись галочки «Запомнить логин» также не соответствовала ожидаемому пользователем сохранению обоих полей. Позднее чтение хранилища могло перезаписать уже вводимые данные.

## Изменения

- Галочка называется «Запомнить логин и пароль». После успешного входа оба значения сохраняются одной записью в `expo-secure-store`. Пароль сохраняется без обрезания пробелов, поле остаётся скрытым при открытии экрана.
- Добавлен отдельный модуль `src/auth/rememberedCredentials.ts`. Новые записи разделены по контуру; для iOS задан режим `WHEN_UNLOCKED_THIS_DEVICE_ONLY`. В SQLite, обычные файлы и журналы пароль не записывается.
- При снятии галочки сохранённая запись заменяется записью без логина и пароля сразу, без ожидания следующего входа. Старые ключи удаляются; отключённая новая запись запрещает восстановление из старых ключей даже при сбое их очистки.
- Неуспешная авторизация не заменяет ранее сохранённые рабочие данные. Ошибка сохранения после успешного входа показывается отдельно и не отменяет вход.
- Чтение и запись последовательно выполняются через общую очередь. Поздний результат прежней попытки входа не отменяет более новый выбор; позднее чтение не затирает ручной ввод и выбор, с которым уже начат вход.
- Биометрия больше не удаляет сохранённый пароль и не требует сохранённого логина для восстановления сессии по refresh-токену. Повторное нажатие защищено; отмена и ошибка биометрии позволяют повторить попытку.

Сохранённый прежней версией логин подставляется по старому ключу. Если старый пароль ещё существует и сохранение было включено, он также читается. Удалённый пароль восстановить невозможно: после установки исправленной версии требуется один успешный вход с отмеченной галочкой.

## Проверка

Добавлены 23 проверки в `tests/rememberedCredentials.vitest.test.ts` и `tests/loginRememberUi.vitest.test.ts`: повторное открытие экрана, холодный перезапуск модуля хранилища, старые ключи, отказ авторизации, ошибки чтения/записи, снятие галочки, позднее чтение, конкурирующие попытки входа и биометрия. Используются только искусственные тестовые данные.

`npm run verify` завершился успешно: 115 Node-тестов и 381 Vitest-тест (всего 496); проверены кодировка 399 файлов, TypeScript и линтер. Android-бандл успешно экспортирован через `expo export --platform android`.

Логи: `mobiel proekt/output/login-remember-fix/verify.log` и `mobiel proekt/output/login-remember-fix/android-export.log`. Исходный экран до этой задачи сохранён в `output/login-remember-fix/source-before`. Предыдущие изменения проекта сохранены.

Исправление внесено в исходники. APK в этой задаче не собирался и на телефон не устанавливался; работа нативного хранилища на реальном устройстве ещё не проверена.
