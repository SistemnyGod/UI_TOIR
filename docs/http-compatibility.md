# Временный HTTP до рабочего релиза

По решению владельца от 10 сентября 2026 года рабочий адрес —
`http://192.168.2.194:5173`. Старые Android-клиенты продолжают использовать HTTP.

В Caddy отключены автоматические HTTPS-редиректы; порт 80 напрямую обслуживает
web, `/api/*` и `/health/*`. В compose порт 5173 направлен на порт 80 прокси.
HTTPS на 443 сохранён для будущей проверки сертификатов, но не навязывается клиентам.
Скрипт Start-Patrol360 проверяет HTTP. Указания HTTPS в release-checklist относятся
к будущему переключению после обновления и проверки телефонов.

На рабочем прокси применён `caddy reload`, без пересборки API, web и Android.
Проверка: web и `/health/ready` отвечают 200; `/api/mobile/bootstrap` без токена
отвечает 401. Ни один из этих HTTP-запросов не перенаправляется на HTTPS.
Вход и синхронизация на физическом телефоне в этой проверке не выполнялись.
