# Архив проектирования

`territory-patrol-panel.zip` содержит прежний статический прототип обходов: HTML, JavaScript, CSS, README и изображения. Архив сохранён 10 октября 2026 года перед удалением каталога из рабочей структуры. Активная реализация находится в `apps/web/src/features/patrol` и `apps/web/src/features/dashboard`.

Архив не входит в сборку и не должен использоваться как источник актуальных контрактов API.
