# Мобильный UI ATOM: изменения и проверка 28.09.2026

Подготовлен подписанный standalone release APK 0.1.32 (33). Изменения UI реализованы, автоматические проверки прошли. Полная приёмка выпуска не завершена: нужны реальные телефоны и сквозной сценарий доставки.

## Что изменено

- Общая светлая/тёмная палитра для текста, полей, состояний, отключённых элементов. Общие кнопки поддерживают загрузку, объяснение недоступности и перенос подписей. Учтено системное уменьшение анимаций.
- Четыре вкладки и вложенные экраны используют общее описание навигации. Нижние панели измеряются через layout; содержимое получает соответствующий отступ. При клавиатуре панель вкладок скрывается.
- Тема доступна до SQLite. Ошибка подготовки приложения содержит краткое объяснение, код, повтор и раскрываемые технические сведения.
- Сохранён брендированный вход; серверный вход и сохранённая смена разделены. Аккаунт и исполнитель показаны отдельно. Существующая локальная разблокировка сохранена.
- Карточки заявок используют существующие действия запуска/продолжения. NFC/QR показывают прогресс и следующую точку. Действия учитывают фактическое состояние обхода.
- Форма точки показывает сохранение, ошибки и повтор внутри формы. Контроллер завершает проверку последней редакции и передачу действия навигации без дополнительного await; ввод при сохранении остаётся доступным.
- Подпись, доступность и действие основной кнопки отправки вычисляются согласованно. Приоритет входа, настройки сервера и исправления сохранён.
- Работы и замечания получили тематические поля и модальные формы. В работах устранены повтор заголовка исполнителя и отсутствие отступов. История отображает ручной осмотр русской подписью «Без NFC — ручной осмотр».
- Настройки обновляют локальную сводку при фокусе и событиях. Раздельно показаны обновление данных, последнее подтверждение отправки и готовность снимка маршрута.

API, миграции SQLite, серверные правила, очередь и подтверждение доставки в этом UI-этапе не изменялись. Рабочий сервер не обновлялся.

## Границы проверки

Тесты контроллера подтверждают ожидание последних символов при задержанной записи и повтор после ошибки. Это не заменяет проверку всех переходов смонтированной формы с ошибкой SQLite. В этой сессии обходы не завершались, результаты точек и отчёты на сервер не отправлялись.

Не выполнены: два физических телефона; реальное NFC; съёмка и доставка фото; камера с восстановлением изменённой формы; все экраны во всех сочетаниях ширины/темы/шрифта; полная проверка офлайн, ошибки авторизации и ожидания вложений на устройстве; измерения памяти/батареи; сценарий «А не закончил → Б завершил офлайн → сервер подтвердил отчёт и файлы → список → перезапуск не возвращает А».
