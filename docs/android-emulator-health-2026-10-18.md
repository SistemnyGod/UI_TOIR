# Проверка Android-эмулятора — 18 октября 2026

## Результат

Эмулятор работоспособен для запуска мобильного приложения, проверки экранов и управления через ADB. Проверка выполнена на существующем профиле Patrol360_UI_20260928, без переустановки приложения и очистки данных виртуального устройства.

| Проверка | Результат |
| --- | --- |
| Android Emulator | 36.4.10.0, build 15004761 |
| Аппаратное ускорение | WHPX установлен и доступен |
| Образ профиля | android-36.1 / google_apis_playstore / x86_64 |
| Система после загрузки | Android 16, SDK 36, x86_64 |
| Загрузка системы | sys.boot_completed=1 |
| Подключение | emulator-5556, ADB device |
| Экран | 1080 × 2400; снимки экрана читаются |
| Установленное приложение | ru.patrol360.mobile, versionName 0.1.48, versionCode 49 |
| Открытие приложения | Status ok, MainActivity, 1348 мс по am start (WARM) |
| Навигация | Обход → Отчёты → Работы → Профиль → Обход |
| Управление | Нажатия, ввод qa в поиск и очистка, прокрутка списка работают |
| Стабильность в проверке | Процесс приложения сохранился; crash buffer пуст |

Проверка выполнена без окна на рабочем столе: экран контролировался через снимки и дерево UI. Отдельное окно Qt в этом прогоне не проверялось. Остальные два AVD не запускались. Это проверка доступности эмулятора и базового UI установленной версии, а не приёмка текущего исходного кода или полный цикл отправки отчётов. Работы и обходы вручную не начинались и не завершались.

Первый запуск из ограниченной среды проверки получил отказ записи в каталог .android. Этот запуск остановлен. Повторный обычный запуск с необходимым доступом успешно загрузился. Права каталогов и конфигурация AVD не изменялись; данные не сбрасывались. Повторяющийся диагностический вывод первого запуска сокращён до начального фрагмента.

После проверки виртуальное устройство штатно выключено командой ADB emu kill. Последняя открытая вкладка — «Обход»; тестовый поисковый ввод очищен.
