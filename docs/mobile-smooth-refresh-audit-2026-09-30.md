# Мобильное приложение: NFC и плавное обновление данных

Дата: 30.09.2026. Проект: `mobiel proekt`.

Исправления внесены в рабочие исходники. Проверялись включение NFC на открытом экране, фоновые обновления заявок, меток, работ, отчётов и уведомлений, догрузка страниц и сохранение заполненных форм.

| Область | Найденная причина | Исправление |
| --- | --- | --- |
| NFC | Событие включения терялось, если ещё выполнялась первоначальная проверка адаптера. Поздний запуск мог показать «сканирование» уже после выключения NFC. | Сохраняется запрос повторного запуска; устаревшие операции отсеиваются. Повторное событие ON не перезапускает работающий reader. |
| NFC на отдельных телефонах | Экран зависел от доставки системного события Android. | Добавлена лёгкая проверка `isEnabled()` раз в секунду только при выключенном NFC, на активном открытом экране. Она не перезагружает маршрут и не меняет интерфейс, пока состояние прежнее. |
| Возврат из настроек | Требовалось заново проверить разрешённость сканирования и состояние маршрута. | При возвращении приложения маршрут перечитывается из локальной БД; reader запускается автоматически. При отмене/завершении обхода он останавливается. |
| Статус связи | Каждые 30 секунд недоступный или неверный сервер снова переключал шапку в «Проверяем», затем обратно. | Проверка продолжается в фоне с последним известным статусом. Интерфейс уведомляется только при его изменении. |
| Заявки | Фоновая синхронизация включала pull-to-refresh и вставляла дополнительную строку в шапку. Сортировка сначала учитывала статус. | Фоновое чтение стало тихим. Ручное обновление включается сразу и защищено от повторного запуска. Сортировка — по плановой дате, новые сверху; ФИО и статус не влияют на порядок. Выбранный обход остаётся отдельной верхней карточкой. |
| Карточка метки | Локальное событие синхронизации повторно запускало сетевое обновление, образуя цикл. | Сетевой запрос выполняется при входе; локальные события перечитывают только данные телефона. |
| Списки | Новые объекты с прежними данными вызывали лишние перерисовки. Анимация строк запускалась при появлении виртуализированных элементов. | Неизменившиеся строки и массивы сохраняют ссылки; убрана анимация появления каждой строки заявок и меток. |
| Прокрутка | Добавление строк сверху могло сдвигать читаемый участок. | Для заявок, отчётов, уведомлений и работ включено сохранение видимого положения. При перестановке существующих элементов нативное удержание отключается: React Native предупреждает о рывках при таком сочетании. Автоматического перехода наверх нет. |
| Работы | Фоновый индикатор менял высоту шапки. Обновление могло отменить догрузку следующей страницы. | Убран фоновый индикатор; обновления объединяются и дожидаются догрузки. Добавленные строки сразу учитываются в размере открытого списка, дубликаты отсекаются. |
| Журнал отчётов | Локальные изменения доставки включали состояние загрузки. Событие или ручной запрос во время чтения могли потеряться. | Локальные чтения тихие; сохраняются поступившие события и запрос следующего обновления. |
| Уведомления | Push не всегда обновлял уже открытый список. Любая синхронизация включала загрузку. | После сохранения уведомлений отправляется событие их обновления. Экран реагирует на нужную область, использует виртуализированный список и перечитывает накопленные события. |
| БД уведомлений | Ответ предыдущего аккаунта мог сохраняться после смены сессии. | Контекст владельца фиксируется до HTTP; проверяется после ответа и внутри транзакции перед commit. Поздние записи и подтверждения прочтения откатываются. |
| Карточки и очередь | Ошибка фонового чтения могла скрыть уже показанную карточку или сводку очереди. | Сохранённые карточки и очередь остаются видимыми; предупреждение не заменяет открытую форму. |

Автотесты проверяют включение NFC без выхода со вкладки, пропущенное системное событие, выключение во время медленного запуска, повторные события ON, остановку при отмене маршрута, сохранение поиска и отсутствие программного сброса прокрутки, защиту от устаревших результатов, ручное обновление, догрузку работ с 25 до 50 строк, сохранение текста и исполнителя в форме работы, комментария и выбранного результата в форме метки, доставку уведомлений и откат реальных транзакций SQLite при смене аккаунта.

Итоговая проверка: **445 тестов** — 100 Node и 345 Vitest в 87 файлах; проверка UTF-8, TypeScript и lint проходят. Android JavaScript/Hermes bundle экспортирован успешно. Логи находятся в `mobiel proekt/output/smooth-refresh-audit/verify-final.log` и `android-export-final.log`; список изменённых файлов — в `changed-files.json`.

Ограничение проверки: новая APK не собиралась и на физическом телефоне эти изменения не запускались. Предыдущая попытка нативной сборки была остановлена недоступной Maven-зависимостью `yearclass:2.1.0`. Успешный экспорт Hermes не подтверждает работу Android NFC-адаптера или отсутствие пропущенных кадров на конкретном устройстве. Для окончательной приёмки нужны включение NFC через настройки и быстрые переключатели, прокрутка при поступлении данных и работа с формой во время отправки отчёта на телефоне.
