# Legacy

Статический прототип перенесён в `docs/archive/territory-patrol-panel.zip`. Активного исходного кода в этом каталоге нет. Работающие адаптеры старых данных остаются у соответствующих модулей в `apps` и `libs`.

Правила:

- CI не собирает legacy-код.
- Новая разработка ведется в `apps`, `libs`, `infra`, `tools`, `tests` и `docs`.
- Перед удалением legacy-файлов нужно убедиться, что полезные сценарии перенесены в активный код или документацию.
