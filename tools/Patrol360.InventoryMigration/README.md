# Разовый импорт Inventory

Утилита использует существующий сервис импорта, отдельно от HTTP API. История прогонов остаётся доступна через GET API; прежние POST импорта возвращают 410.

Запускайте через `tools/Prepare-InventoryMigrationDatabase.ps1`, передав `-TargetConnectionString` восстановленной копии и `-LegacyConnectionString` источника. Имя целевой БД обязательно начинается с `patrol360_migration_`. Рабочая `patrol360` запрещена. Сначала выполните `-DryRunImport`, затем при необходимости `-RunImport -IUnderstandThisIsCopy`.

Передавайте строки подключения через защищённое окружение или переменные своей оболочки; не сохраняйте пароли в исходниках. Утилита получает `INVENTORY_MIGRATION_TARGET` и `INVENTORY_LEGACY_CONNECTION_STRING`; единственный аргумент — `--dry-run` или `--import`. Она не запускает фоновые интеграции и не применяет миграции автоматически. Сначала восстановите копию и примените совместимую схему.

Импорт не запускался в ходе очистки 10 октября 2026 года. Код переноса и идентификаторы старых записей сохранены для восстановления.
