# Мобильные аккаунты

`MobileAccountsScreen` управляет выбором аккаунта, открытием окон и общей политикой закрытия. Редактор получает снимок выбранного аккаунта; команды передают его ID явно, независимо от последующего выбора строки и фонового обновления.

Компоненты разделены по операциям:

- `MobileAccountCreateDrawer` — создание и способ задания пароля;
- `MobileAccountEditPanel` — редактирование параметров;
- `AccountEditConfirmation` — общее вложенное подтверждение изменения с pending и возвратом фокуса;
- `MobileAccountLinkPanel` — состав привязанных сотрудников;
- `MobileAccountActionPanels` — сброс пароля и удаление;
- `MobileAccountDetail` — просмотр аккаунта, устройств и событий;
- `accountFormParts` — элементы оформления форм;
- `useAccountPanelState` — владение незавершённым запросом и уведомление о состоянии черновика.

Окна используют общий стек фокуса, `inert` фона и подтверждение потери ввода. Успешное сохранение закрывает редактор отдельно от пользовательской отмены. Смена владельца данных перемонтирует рабочую область; ответ закрытого редактора не вызывает его обработчики.

Договорённости HTTP API и мобильного приложения остаются прежними. Не сохранять пароли в browser storage, уведомлениях или логах.
